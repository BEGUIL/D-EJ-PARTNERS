# EJ&PARTNERS — site vitrine

Version statique multipage bilingue français/anglais, sans dépendance ni outil de compilation.

## Pages

`index.html`, `cabinet.html`, `expertises.html`, `expertise-cybersecurite.html`, `secteurs.html`, `approche.html`, `formations.html`, `publications.html` et `contact.html`.

## À valider avant publication

- Remplacer le symbole CSS provisoire par le logo officiel SVG/PNG.
- Valider les couleurs, textes, coordonnées et mentions légales.
- Connecter le formulaire à un canal de réception sécurisé : il ne transmet actuellement aucune donnée.
- Remplacer les publications provisoires par les contenus validés du cabinet.

Ouvrir `index.html` dans un navigateur pour prévisualiser le site.
